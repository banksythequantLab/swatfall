# Credits

SWATFALL uses **no third-party art, audio, or font assets.**

* All 3D models (glowmoth, urchin, lumen, emitter, playfield) are procedural geometry written in `src/art.js`.
* All sounds are synthesized at runtime with the WebAudio API in `src/audio.js`.
* Text uses the device's system UI font.

Libraries:
* [three.js](https://threejs.org/) — MIT License
* [Vite](https://vitejs.dev/) — MIT License (build tool)
* [Vitest](https://vitest.dev/) — MIT License (tests)

The game's mechanics (a cannon at the bottom of a field firing at a descending formation) are a classic arcade genre; SWATFALL's name, creatures, visuals, sounds and its hand-swat diver mechanic are original.
